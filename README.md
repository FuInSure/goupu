# 构·谱——中国古代建筑基因图谱

一个本地运行的信息可视化作品。中央以建筑与特征关系为核心，四周以图表联动探索。项目不使用地图、经纬度或地理底图。

桌面主页面已改为随浏览器视口高度自适应，压缩页头、留白和图表间距。宽度1100px以上、高度600px以上时采用一屏工作台；名录、详情及短窗口中较长的材料列表在各自区域内部滚动。较窄或更矮的窗口保留自然页面滚动，保证内容可以访问。

主页面保留01—04，分布在中央图谱两侧。四个面板拉开间距，并使用删除05后腾出的高度，图形保持自然比例。

图表保留自然比例：矩阵使用居中的方形格子，散点绘图区宽高比不超过1.8；大屏工作台最大宽度1480px并居中，避免页面与图形横向过度展开。


## 打开作品

最直接的方法：双击根目录的 `启动作品.cmd`，或用 Edge / Chrome 打开 `site/dist/index.html`。

页面、样式、程序和数据均在本地，无需联网、登录或安装依赖。官网来源与配图链接需要联网查看。

若希望通过本地地址访问，在本项目目录打开 PowerShell：

```powershell
npm start
```

打开 `http://127.0.0.1:4173`。终端出现“构·谱 local preview”表示服务已启动；关闭服务可按 Ctrl+C。端口占用时可在当前终端设置 `$env:ATLAS_PORT = '4174'` 后再次执行 `npm start`。

## 探索方式

原始资料与后续补充数据已合并为一个视图，保留140个对象、1,051条关联。顶部数据切换栏及其逻辑已删除，图谱、图表、详情、比较与导出始终使用同一组数据。界面采用统一的连线、散点与矩阵编码，节点颜色区分建筑类型。

按用户说明的个人练习用途，已移除界面的模拟声明、字段标签，以及悬停、比较、名录、资料弹窗中的相关文案；保留资料来源、年代说明与图表操作说明。

模拟层单独保存在 `site/dist/simulation.json` / `simulation.js`，按建筑类别和固定随机种子生成1,333项字段，不覆盖 `data.json` / `data.js`。包括形制、材料、局部开间、面积、高度和桥梁尺度。建筑群采用代表性单体示例，不能当成建筑群总体测绘。未生成文献来源、建筑年份或建造事件。

- 营造图谱：按住圆盘拖动旋转，滚轮直接缩放，Shift拖动平移以浏览放大后的内容。名称与圆点都可点击；点击建筑持续突出其关联，并展开探索卡片。卡片可以查看资料、联动此建筑，或点击特征寻找同类对象。旋转时标签按朝向调整，复位按钮恢复角度、位置和缩放；完整名录始终保留全部匹配对象名称。
- 资料范围：全部资料140个、有形制资料55个、有开间资料23个、文保名录样本90个。形制与开间范围依据条目原有字段记录判断；类型构成图随范围切换显示各类型数量与占比，灰条表示范围占比、彩条表示当前匹配占比，四类行固定分散排布。点击类别继续与范围、搜索及其他条件取交集。
- 图表联动：类别、材料证据、屋顶与开间矩阵、开间与进深散点、图表都使用同一组筛选条件。条件显示在顶部，可单独清除或全部重置。
- 特征组合：用途／主题类型、文献时期与已知形制组成流带。点击节点或流带，筛选实际组合。年代争议单独归组。
- 建筑比较：在两座建筑的详情里分别“加入比较”，再查看共同特征与并排字段。局部尺度不用于整座建筑总体排名。
- 寻找相近建筑：按已知共同建筑特征数排序，排除地域和文献时期，不把缺失当差异，不推断历史传承。
- 导出数据：导出当前匹配对象的 JSON，包含来源、缺口、筛选条件与口径。窄屏的资料和导出入口在页面底部。

键盘支持：`/` 聚焦搜索；Tab 切换可操作节点；Enter 或空格触发图表节点；Esc 关闭详情和原生对话框。尊重系统的“减少动态效果”设置。

按钮具备按下反馈、选中状态或结果提示。材料可再次点击取消；重复点击当前探索视图保留筛选；缩放边界显示禁用状态；比较清单未满两座时提示“再选一座”。操作提示不遮挡比较按钮。

## 数据与参赛范围

首版收录140个对象：民居39、官府7、皇宫49、桥梁45。计数对象包括文保单位、建筑群以及故宫局部单体，不能解释为全国建筑总量或总体抽样。39个对象有屋顶形制记录，23个对象有成对开间资料。

统一视图有95个房屋开间展示样本、45个桥梁尺度展示样本，形成1,051条特征关联；其中原始实证关系477条，其余574条来自模拟字段。模拟模式的比例与分布仅用于界面演示，不作为历史结论、研究数据或真实参赛证据。原始资料文件仍保留原值与资料缺口。

来源包含文化和旅游部转载第六批国保名录、国家林业和草原局转载第八批国保名录、北京建筑大学存档的第五批名录，以及故宫博物院官方建筑解说。第五批为辅助转载来源，正式审定前仍应对照政府原文复核。

断虹桥的年代争议保留为“元或明初”；其桥宽为最宽处，不当作净跨度。太和殿重建工程起点与竣工分别记作1695和1697；乾清宫始建和现存建筑重建分开记载。建造与重建事件保留在建筑详情，不把朝代边界转成建筑年份。

名录年代与官方解说历史沿革时期在详情中标明口径。材料缺失保留空值，屋面、桥面与承重材料分别表述；屋顶、开间仅代表主体正殿或门楼等记录范围。尚未复制官网照片，仅提供来源链接，图片再用许可待核实。

参照用户提供的2026通知设计，未办理报名或上线。后续参赛需核对对应届次主题与要求；2026通知附件4未列Codex，本次AI辅助制作不能视为已经满足参赛工具限制。使用本作品正式参赛前，需要向组委会核对适用口径。

## 文件与验证

| 路径 | 内容 |
| --- | --- |
| `site/dist/` | 可直接打开的作品、数据JSON和数据脚本 |
| `scripts/build_data.py` | 从本地来源快照重建结构化数据 |
| `scripts/build_simulation.py` | 生成独立、可重复的模拟展示层 |
| `scripts/collect_sources.py`、`collect_details.py` | 带重试和增量保存的资料采集 |
| `research/` | 官方来源快照及辅助转载存档；不是全部资料均被纳入作品 |
| `scripts/verify-data.mjs` | 对象去重、范围、来源、缺失、重点形制与年代校验 |
| `scripts/verify-simulation.mjs` | 模拟字段标记、适用类型、来源隔离与原值保护校验 |
| `scripts/browser-qa.mjs` | 本机Edge交互与响应式验收 |
| `scripts/rotation-qa.mjs` | 200%／300%实际拖动、连线缓存、标签方向与高频事件检查 |
| `output/qa/` | 验收截图、数据校验和浏览器验收记录 |
| `设计说明.md` | 项目问题、视觉编码、交互关系与验证边界 |

代码无运行时第三方依赖；本地预览和Node校验需Node.js。重新采集／构建数据需要Python与PyMuPDF。原始快照已保留，普通用户打开页面不需要这些工具。

```powershell
npm run check
npm test
```

浏览器验收需先启动 `npm start`，然后运行 `node scripts/browser-qa.mjs`。该脚本使用本机Edge的隐藏独立浏览器配置，不使用个人浏览器资料。

圆盘性能检查运行 `node scripts/rotation-qa.mjs`，结果保存在 `output/qa/rotation/results.json`。拖动按动画帧合并更新，连线复用当前筛选及选中状态的缓存图像，文字和节点保持实时显示；松手后恢复矢量连线。缩放仅在名称显示规则变化时重建节点。帧间隔属于本机无头Edge测量，不能代替其他设备的实际体验。
